# Bible quote source

Editorial review: 2026-09-02

## Base edition and public domain status

All 365 quotations use a single textual source: the **World English Bible Updated**, an American English Bible translation published by eBible.org. The publisher dedicates the text to the public domain and permits copying, distribution, quotation, and inclusion in applications:

- https://ebible.org/bible/details.php?all=1&id=engwebu
- https://ebible.org/engwebu/copyright.htm

The catalogue was generated from the official verse-per-line download (`engwebu_vpl.zip`). The application includes the resulting passages locally and never fetches Bible text at runtime.

## Editorial method

1. The existing set of 365 references was retained so the catalogue continues to prioritize hope, wisdom, faith, love, courage, peace, and care.
2. Each reference was matched to its exact verse in the official World English Bible Updated dataset.
3. Every entry was checked for a non-empty identifier, text, and English reference, as well as uniqueness and suitability for the daily quote card.
4. The text is stored unchanged from the source. Book names in the displayed references use standard US English names.
5. The deterministic 365-day rotation and fully offline behavior are preserved.
